## 测试目的与根因

通用公开 API 检查要求：`__all__` 中的对象必须声明合法公开所属模块。
`from ._inductor_profiler import inductor_trace_handler` 不会自动重写函数的 `__module__`，
因此原 PR 的导出列表与函数元数据矛盾。来源已在文档仓
`docs/pr_46073_origin_analysis.md` 核对。

这不是算子分发或数值行为问题；属于 Python 公开接口元数据缺陷。
